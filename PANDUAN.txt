PORTFOLIO HTML JORDEN SIEW — PANDUAN RINGKAS

1. Ekstrak keseluruhan fail ZIP ke satu folder.
2. Buka index.html menggunakan Chrome, Edge atau Firefox.
3. Imej dan video portfolio dipautkan daripada folder assets. Jangan pindahkan index.html keluar daripada folder ini.
4. Untuk memaparkan PDF terkini, pergi ke bahagian “Portfolio PDF terkini”, tekan Choose File/Pilih Fail dan pilih PDF daripada komputer.
5. PDF dipaparkan secara setempat dalam pelayar sahaja. Ia tidak dimuat naik ke internet dan pilihan PDF tidak kekal selepas halaman ditutup atau dimuat semula.
6. Untuk menerbitkan laman web kepada orang lain, muat naik keseluruhan folder bersama assets ke hosting web. Ruang pilih PDF ialah pratonton setempat; untuk membolehkan semua pelawat melihat PDF yang sama, letakkan PDF di hosting dan pautkannya dalam HTML.

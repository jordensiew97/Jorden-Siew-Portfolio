PORTFOLIO HTML JORDEN SIEW — PANDUAN RINGKAS

1. Ekstrak keseluruhan fail ZIP ke satu folder.
2. Buka index.html menggunakan Chrome, Edge atau Firefox.
3. Imej, video dan PDF portfolio dipautkan daripada folder assets. Jangan pindahkan index.html keluar daripada folder ini.
4. Bahagian “Portfolio Oden New Multimedia 2026” kini memaparkan PDF yang disediakan untuk semakan panel interview. Panel boleh membaca PDF terus di laman web, membuka PDF dalam tab baharu atau memuat turunnya.
5. Jika laman web diterbitkan ke internet, muat naik keseluruhan folder termasuk folder assets supaya PDF dan media dapat dipaparkan kepada panel.
